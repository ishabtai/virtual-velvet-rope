# Financial Modeller

**ID:** 07 · **Folder:** `agents/07-financial-modeller` · **Agent definition:** `.claude/agents/financial-modeller.md`

## Mission
Build the unit economics and financial model for each business-model option.

## Key research questions
- Startup capital by option (per machine and total).
- Revenue benchmarks per machine per week/month in Australia by location type.
- Cost structure: COGS, commission, card fees, telemetry, fuel, insurance, depreciation, GST/BAS.
- Breakeven, payback, cash flow at 1 / 5 / 20 machines; sensitivity analysis.
- Small-business finance and tax considerations (instant asset write-off, depreciation).
